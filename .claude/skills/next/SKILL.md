## 작업 지시

1. git log로 최근 커밋 10개를 확인하여 작업 흐름 파악
2. 루트 docs/todos.md에서 미완료 항목(- [ ]) 수집 (프로젝트 구분 없는 우선순위 순 평면 목록, 위가 우선순위 높음)
3. 메모리 파일 확인
4. 위 정보를 기반으로 다음을 수행:
   - 미완료 태스크를 우선순위 순으로 정리 (도메인 태그 참고)
   - 최근 커밋 흐름에서 현재 진행 중인 작업 맥락 파악
   - 다음 작업 후보를 우선순위 순으로 2~3개 제안
     - 의존성 고려 (예: API 구현 후 프론트 연동)
     - 연관성 고려 (예: 같은 기능을 api-v1, api-v2 양쪽에 구현)
     - 인프라 선행 작업 여부

## 규칙

- 제안만 하고, 사용자 승인 전까지 구현하지 않음
- 추측하지 않고 todos.md와 커밋 히스토리에 근거하여 제안
- 간결하게 제안 (후보당 2~3줄)
